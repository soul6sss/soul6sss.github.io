                      第一章 介绍mybatis

                      MyBatis 是一个 ORM 持久层框架，用于简化 Java 与数据库之间的交互

                      ORM：

                      全称：

                      xxxxxxxxxx
                      Object Relational Mapping

                      翻译：

                      对象关系映射

                      1. 只有：接口。没有：实现类。为什么：还能：调用？因为：Spring：启动：以后。MyBatis：自动：生成：代理对象。

                      2. xml中写真正的sql语句

                      3. 优点：

                        ① SQL 与 Java 分离

                        ② 自动封装对象

                        ③ 减少 JDBC 代码

                        ④ 易维护

                        ⑤ 支持动态 SQL

                        ⑥ 学习成本低

                      十四、期末考试最爱考的一个点（★★★★★）

                      下面是老师最喜欢出的代码题：

                      接口：

                      xxxxxxxxxx
                      public interface UserMapper {
                      

                          User findById(Integer id);
                      

                      }

                      请补全 XML：

                      xxxxxxxxxx
                      <mapper namespace="____________">
                      

                          <select id="____________"
                                  resultType="User">
                      

                              select *
                              from user
                              where id=#{id}
                      

                          </select>
                      

                      </mapper>

                      答案：

                      xxxxxxxxxx
                      <mapper namespace="com.xxx.mapper.UserMapper">
                      

                          <select id="findById"
                                  resultType="User">

                      记住两个对应关系：

                      • namespace ⇔ Mapper 接口全限定类名

                      • id ⇔ Mapper 接口方法名

                      这两个知识点几乎是 MyBatis 期末考试的必考内容
