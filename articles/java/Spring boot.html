                                                                  第五章AOP

                                                                  AOP 是一种面向切面编程思想，它可以在不修改原有业务代码的基础上，对程序进行统一功能增强

                                                                  1. 切面

                                                                  对于一个活动的前后中能操作的地方

                                                                  2. Aop作用

                                                                  日志

                                                                  事务

                                                                  权限

                                                                  缓存

                                                                  异常

                                                                  性能统计

                                                                  3. 核心

                                                                  1. JoinPoint(连接点)：所有可以被增强的方法 一般指类

                                                                  2. PointCut切点：切点就是实际要增强的方法

                                                                  3. Advice（通知）实际增强所加入的功能

                                                                    1. 前置通知

                                                                    2. 后置通知

                                                                    3. 返回通知

                                                                    4. 异常通知

                                                                    5. 环绕通知

                                                                  4. Aspect（切面）切点+通知

                                                                  5. Weaving:织入，什么时候放进去

                                                                  4.底层实现

                                                                  Aop实现实际上是使用了动态代理

                                                                  1. JDK动态代理：在有接口的情况下使用

                                                                  2. CGLB动态代理：没有接口的情况下使用

                                                                  5.具体使用

                                                                  3. 通知

                                                                    1. 是整个请求的负责人，收到请求后，会查找对应的Controller,然后再调用Controller,返回结果

                                                                    2. DispatcherServlet 是 Spring MVC 的前端控制器，负责统一接收请求、分发请求、调用 Controller，并将结果返回给客户端。

                                                                  3. HandlerMapping（处理器映射器）

                                                                    1. DispatcherServlet收到对应请求，会先找HandlerMapping,里面的Map集合中存储对应的地址和对应controller,返回这个结果给DispatcherServlet

                                                                    1. 将返回的数据还原成json，即return "string",其中字符串会解析成json
